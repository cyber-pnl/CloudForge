# Rule 07 — CI

The project intentionally uses one CI workflow:

```text
.github/workflows/ci.yml
```

Do not create additional workflows unless the architecture explicitly changes.

The CI pipeline should remain understandable.

Expected stages:

```text
Checkout
    ↓
Tests
    ↓
OpenTofu formatting
    ↓
OpenTofu validation
    ↓
Trivy
    ↓
Floci
    ↓
OpenTofu plan
    ↓
Integration tests
```

CI should fail fast on deterministic validation failures.

Do not hide errors.
